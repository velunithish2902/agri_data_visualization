# 🌾 AgriData Explorer: Understanding Indian Agriculture with EDA

An end-to-end **Data Analytics & Visualization project** focused on analyzing Indian agricultural production using **Python, SQL (PostgreSQL), and Power BI**.  
This project provides interactive insights into crop production, yield, and cultivated area across Indian states and districts.

---

## 📌 Project Overview

India’s agricultural data is vast, complex, and spread across different regions. This project builds a **data visualization platform** to help:

- ✅ Farmers choose better crops
- ✅ Policymakers identify low-productivity regions
- ✅ Researchers analyze long-term agricultural trends

---

## 🎯 Objectives

- Clean and standardize raw agricultural data  
- Perform **Exploratory Data Analysis (EDA)**  
- Store structured data in **PostgreSQL**  
- Build an **interactive Power BI dashboard**  
- Answer real-world agriculture-based business questions  

---

## 🧰 Technologies Used

- **Python** – Data Cleaning & EDA  
- **Pandas, NumPy, Matplotlib, Seaborn** – Data Processing & Visualization  
- **PostgreSQL** – Database Storage  
- **SQL** – Querying & Analysis  
- **Power BI** – Dashboard & Reporting  
- **GitHub** – Version Control  

---

## 📂 Dataset Information

- **Source**: ICRISAT District-Level Agricultural Data  
- **Key Fields**:
  - Dist Code  
  - Year  
  - State Code  
  - State Name  
  - District Name  
  - Crop Area (1000 ha)  
  - Crop Production (1000 tons)  
  - Crop Yield (Kg/ha)  

- **Crops Covered**:
  - Rice, Wheat, Maize, Sorghum  
  - Millet, Barley  
  - Pulses (Chickpea, Pigeonpea, etc.)  
  - Oilseeds, Sugarcane, Cotton  
  - Fruits, Vegetables, Fodder  

---

## 🔄 Project Workflow

1. **Data Collection**
   - Collected district-level agricultural data

2. **Data Cleaning & Preprocessing**
   - Removed null values
   - Standardized column names
   - Converted units (Area, Production, Yield)

3. **Database Creation**
   - PostgreSQL database created
   - Cleaned data inserted using Python + SQL

4. **Exploratory Data Analysis (EDA)**
   - Production trends
   - Yield analysis
   - Crop comparisons

5. **Power BI Dashboard**
   - Interactive visuals
   - Filters by Year, Crop, State
   - KPI Indicators

## 📑 How to Run This Project

1. Clone the repository  
2. Install required Python libraries  
3. Run Python scripts for data cleaning  
4. Insert data into PostgreSQL  
5. Open Power BI and connect to PostgreSQL  
6. Load the `dist_agri` table  
7. Build dashboard or open provided `.pbix` file
